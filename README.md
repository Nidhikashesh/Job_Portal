# Job_Portal
# 💼 Job Portal Website

A full-stack Job Portal web application where admins can create, manage, and delete job postings, and users can browse and search jobs easil.

---

## 🚀 Features

- 📝 Create Job Posts (Admin)
- 🗑 Delete Job Posts
- 🔍 Search Jobs (by Company Name & Role)
- 🖼 Upload Company Logo (Image)
- 📅 Manage Job Dates (Start & Last Date)
- 📱 Responsive UI (Mobile Friendly)
- ⚡ Fast & Simple REST API Integration

---

## 🛠 Tech Stack

### Frontend
- HTML5
- CSS3
- EJS (Embedded JavaScript Templates)

### Backend
- Node.js
- Express.js

### Database
- MongoDB (Mongoose)

### Other Tools
- Multer (Image Upload)
- Fetch API (for DELETE & Search)
- bcrypt(for encrypt password)
- connect-flash(for flash massages)
