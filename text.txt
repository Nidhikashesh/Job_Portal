You need a functional search (frontend + backend) that filters jobs by company name OR job role. The correct approach is:

👉 Input field → query param → backend filter (MongoDB $regex) → render filtered results

✅ 3. Backend (IMPORTANT – Main Logic)

Update your /admin route:

router.get("/admin", async (req, res) => {
    try {
        const search = req.query.search || "";

        const query = {
            $or: [
                { companyName: { $regex: search, $options: "i" } },
                { jobRole: { $regex: search, $options: "i" } }
            ]
        };

        const jobs = await Job.find(query).sort({ createdAt: -1 });

        res.render("admin", { jobs, search });

    } catch (err) {
        console.log(err);
        res.send("Error loading jobs");
    }
});


---

🔍 How It Works

$regex → allows partial matching

$options: "i" → case-insensitive

$or → search in both fields
